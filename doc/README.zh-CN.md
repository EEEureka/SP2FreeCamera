# SP2 Free Camera（简体中文）

`SP2 Free Camera` 是适用于 Windows x64 版 `SimplePlanes 2` 的本地自由相机插件。
当前版本为 `0.6.9`，使用 `BepInEx 5 Mono x64` 加载，已针对游戏版本 `0.7.6.100f`
构建。插件只操作本地相机和本地 UI，不修改载具物理，不发送网络消息，也不依赖其他自定义插件。

## 直接安装

仓库的 `release` 目录提供可部署压缩包：

[`release/SP2FreeCamera-v0.6.9-win-x64.zip`](../release/SP2FreeCamera-v0.6.9-win-x64.zip)

压缩包已经包含 Free Camera DLL 和完整的 BepInEx `5.4.23.5` Windows x64 运行时，
不需要另行安装 BepInEx。

1. 完全关闭 `SimplePlanes 2`。
2. 打开压缩包，将其中全部内容直接解压到游戏根目录，也就是
   `SimplePlanes 2.exe` 所在目录。
3. 如果系统询问是否合并 `BepInEx` 文件夹，选择合并。
4. 启动游戏并进入飞行场景。

安装后的关键文件结构如下：

```text
SimplePlanes 2/
├─ .doorstop_version
├─ doorstop_config.ini
├─ winhttp.dll
├─ BepInEx/
│  ├─ core/
│  └─ plugins/
│     └─ SP2FreeCamera.dll
└─ SimplePlanes 2.exe
```

发布包不包含 `BepInEx/config`、日志、缓存或其他插件，所以覆盖安装不会重置现有
Free Camera 配置。压缩包的 SHA-256 位于
[`release/SHA256SUMS.txt`](../release/SHA256SUMS.txt)。

## 默认操作

| 操作 | 默认输入 |
| --- | --- |
| 进入/退出自由相机 | `Insert` |
| 打开/关闭独立菜单 | `ScrollLock` |
| 向前/向后移动 | `W` / `S` |
| 向左/向右移动 | `A` / `D` |
| 向上/向下移动 | `E` / `Q` |
| 普通/快速速度切换 | `Keypad5` |
| 锁定自己的载具或角色 | `Backspace` |
| 锁定游戏当前选中的目标 | `-`（主键盘数字行） |
| 切换自动 FOV | `=`（主键盘数字行） |
| 锁定鼠标下的地形、部件或移动对象 | 鼠标中键 |
| 解除锁定并自由观察 | 按住鼠标左键拖拽 |
| 调整 FOV；自动 FOV 生效时调整期望参考面积 | 鼠标滚轮 |

普通移动速度默认是 `200 m/s`，快速移动速度默认是 `2000 m/s`。从旧版本升级时，
插件只会把仍等于旧默认值 `20/200 m/s` 的对应配置迁移为新默认值；其他自定义速度保持不变。

配置文件在首次运行后生成：

```text
BepInEx/config/local.sp2.freecamera.cfg
```

插件内置 English 和简体中文界面。可从快捷菜单或完整设置菜单切换语言。

## 相机进入与鼠标输入

进入自由相机时会立即将滚转角归零，使画面恢复水平，同时保留当前相机位置、航向、俯仰及 FOV。

HUD 目标框不会中断鼠标左键拖拽，也不会拦截滚轮；可以在目标框上开始拖拽并连续跨过其边界。
手动 FOV 与自动 FOV 参考面积调整均适用，中键选取目标也使用相同的输入边界。
插件菜单、前景游戏控件、弹窗、文本输入框和开发者控制台仍保留原有输入保护。

## 电影感位置运镜

按 `ScrollLock` 或通过快捷菜单的设置按钮打开二级完整设置菜单，在“数值设置”中
分别输入“普通模式位置加速度 (m/s²)”和“快速模式位置加速度 (m/s²)”，再点击“应用数值”。
普通默认 `80 m/s²`，快速默认 `800 m/s²`，两项范围均为 `0–1000000`，分别保存为
配置文件中的 `[Movement] NormalAcceleration` 和 `FastAcceleration`。

当前模式的加速度限制相机自身位置移动速度的变化率，起步、松键刹停和改变移动方向均生效。
切换模式时保留当前速度，并立即采用新模式的加速度；快速切回普通时也按普通加速度减速。
键盘和快捷菜单方向按钮使用相同行为。
速度保存在世界坐标系中，因此移动中改变观察方向时，运动轨迹会逐渐转弯。
锁定目标也会保留正在进行的位移速度，避免中途突然刹车。

“位置移动平滑时间”由两种模式共用，默认 `0.08 s`，用于柔化接近目标速度或停止时的收尾。
平滑时间设为 `0` 后，位置移动仍按当前模式的加速度起步和刹停。某模式的加速度设为 `0`
会关闭该模式的加速度限制；该模式的加速度与移动平滑时间同时为 `0` 时才会即时移动。

加速度越小，起步和刹停越缓，滑行距离也越长。慢速拍摄可从普通速度 `20 m/s`、
普通加速度 `20 m/s²`、移动平滑时间 `0.15 s` 开始调节。在默认速度与加速度下，
普通和快速模式从静止加速到各自目标速度均至少需要 `2.5 s`，平滑收尾会进一步延长最终过渡。
快速切回普通后按普通加速度减速，降速过程可能更长。松开移动键后会逐渐减速，请预留刹停距离。

上述配置只影响相机自身位置。鼠标观察旋转、动态目标逐帧直接锁定与 FOV 缩放仍各自独立。
锁定后可能继续完成先前移动输入引起的刹停，但目标自身不会拉动相机位置。
打开完整菜单、输入焦点被占用、退出自由相机或单帧间隔超过 `0.25 s` 时仍立即清除移动速度。

## 锁定行为

- 部件、离架武器、动态地面目标、自己的载具/角色和游戏当前目标，会在每个画面帧
  读取当前原始目标点并直接调整相机朝向。
- 动态锁定不使用目标预测或聚焦平滑，也不会带动相机位置。
- 手动与自动 FOV 均与锁定朝向相互独立，始终使用菜单中配置的 FOV 平滑时间。
- 菜单中的“地形点锁定平滑时间”只影响地形点等静态焦点。
- 左键开始拖拽后会解除当前锁定，恢复自由观察。

## 自动 FOV / 参考成像面积锁定

自由相机启用期间，按主键盘 `=` 切换自动 FOV。完整设置菜单和快捷菜单也提供开关，
并显示“关闭”“等待目标”或“生效中”。对应可配置键位为
`[Keys] ToggleAutoFov = Equals`，不是小键盘的 `KeypadPlus`。

锁定有效目标时，插件以锁定点为球心的**虚拟单位球**投影面积为参考，自动补偿距离变化。
地形、部件、离架武器、动态地面目标、自己的载具/角色及当前游戏目标均使用相同规则。
不会实际创建或渲染球体，也不读取真实目标尺寸、朝向、机翼展开状态或模型轮廓。
此模式不会改变相机自身位置。

- 开启并生效或切换目标时，以当前实际显示的 FOV 建立初始构图（`100%`），避免跳回旧缩放值。
- 生效时，滚轮调整相对于初始构图的期望参考**面积**。显示的百分比不是实际目标占据屏幕的比例；
  滚轮灵敏度沿用现有缩放灵敏度配置。
- 每个画面帧使用与锁定朝向相同的最新目标位置计算理想 FOV。实际 FOV 与手动缩放一样使用
  “FOV 平滑时间”（默认 `0.12 s`）；非零平滑允许快速远近变化期间比例暂时偏离，`0` 时直接
  应用几何计算结果。
- 没有有效目标时保持待命，滚轮正常调整 FOV。左键拖拽解除锁定，但保留模式开关状态。
- 关闭模式时保留当前实际 FOV，滚轮恢复手动缩放。目标丢失后停止追逐失效距离；重新锁定时
  建立新的构图基准。
- 达到 FOV 限制或进入虚拟参考球内部/表面时只做静默保护。距离变化触发限幅不会改写期望比例，
  距离恢复后继续补偿；在限幅处反向滚动，不需要先抵消积累的越界输入。

插件加载时默认关闭该模式。当前游戏会话中进入/退出自由相机会保留开关，但不写入配置文件，
重启游戏后恢复关闭。操作与边界场景可参考[测试清单](testing/auto-fov.md)。

## 卸载

只卸载 Free Camera 时，删除：

```text
BepInEx/plugins/SP2FreeCamera.dll
```

如果还有其他插件使用 BepInEx，请勿删除 `BepInEx`、`winhttp.dll` 或
`doorstop_config.ini`。

## 从源码构建

构建需要：

- Windows PowerShell 5.1 或 PowerShell 7
- Visual Studio Build Tools（Roslyn C# 编译器）
- 本机安装的 `SimplePlanes 2`

通过环境变量指定游戏目录，然后构建：

```powershell
$env:SP2_GAME_DIR = '<SteamLibrary>\steamapps\common\SimplePlanes 2'
.\build.ps1
```

如果脚本无法自动找到编译器，可显式传入一个通用位置：

```powershell
.\build.ps1 -Csc '<VisualStudio>\MSBuild\Current\Bin\Roslyn\csc.exe'
```

构建并生成完整可部署压缩包：

```powershell
.\build.ps1 -Package
```

构建并部署 DLL 到本机游戏（游戏运行时脚本会拒绝覆盖）：

```powershell
.\build.ps1 -Deploy
```

构建结果位于 `bin/SP2FreeCamera.dll`，发布包位于 `release`。打包脚本只会从
BepInEx 官方发行地址下载版本 `5.4.23.5`，并校验官方 SHA-256：

```text
82f9878551030f54657792c0740d9d51a09500eeae1fba21106b0c441e6732c4
```

`verify-release.ps1` 会复核压缩包文件白名单、BepInEx 逐文件哈希、DLL 版本，
并扫描本机用户路径、仓库路径、UNC 路径和私网地址。

无需启动游戏即可运行相机输入、自动 FOV 与位置运动回归测试：

```powershell
.\test-camera-input.ps1
.\test-auto-fov.ps1
.\test-movement.ps1
```

相机输入测试使用最小 Unity/UI 替身执行生产代码中的进入及鼠标输入判断方法，覆盖滚转归零、
连续跨越目标框、滚轮、UI 保护及事件系统切换；这些源级测试不能替代实际游戏内的渲染与交互检查。

FOV 测试覆盖单位球投影、滚轮比例、状态切换、静默限幅、近距离保护、视口宽高比变化及共用
缩放平滑。运动测试覆盖加速、刹停距离、转向、反向、速度切换、平滑组合及不同画面帧率下的位移一致性。

## 当前边界

- 当前仅支持非 VR 飞行场景。
- 最小 FOV 为 `0.1°`；极小 FOV 会使用自定义透视矩阵。
- 如果目标原始 Transform 只在物理帧更新，逐画面帧直瞄仍只能使用当时可见的原始位置。
- 实际游戏版本升级后，建议重新构建并进行飞行场景回归测试。
