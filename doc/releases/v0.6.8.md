## Automatic FOV and reference-area lock

- Press **`=` on the main keyboard** to toggle automatic FOV. Both plugin menus provide the same toggle and show off, waiting, or active status.
- Supports every valid focus type: terrain points, aircraft parts, released weapons, dynamic ground targets, your vehicle/avatar and selected game targets.
- Compensates distance changes using the projected area of a **virtual unit sphere** at the focus point. Real target size, orientation and mesh shape are intentionally ignored; the mode never translates the camera.
- While active, the mouse wheel changes the desired reference **area** relative to the initial framing (`100%`). This is not the real target's screen coverage.
- Automatic and manual zoom share **FOV smoothing time**. Nonzero smoothing allows temporary size drift during rapid distance changes; `0` applies immediate compensation. Moving-target rotation remains immediate and independent.
- Without a valid target, the mode waits and the wheel adjusts FOV manually. Left-drag clears focus but keeps the mode armed. Disabling the mode retains the currently displayed FOV; a newly selected target captures a fresh baseline.
- FOV limits and positions on/inside the reference sphere are handled silently. Returning to range recovers the requested ratio; reverse wheel input at a limit responds without accumulated out-of-range input.
- Zoom is applied once per rendered frame using the same fresh target sample as focus rotation, including the existing sub-degree custom projection path.

## Installation and upgrade

Download **SP2FreeCamera-v0.6.8-win-x64.zip**, close SimplePlanes 2, and extract all contents into the directory containing `SimplePlanes 2.exe`. The archive includes **BepInEx 5.4.23.5 Windows x64**. Merge existing folders; the package contains no personal configuration or other plugins.

Existing settings are preserved. The new configurable key is `[Keys] ToggleAutoFov = Equals`, not `KeypadPlus`. Automatic FOV starts off when the game launches; its switch is retained during that game session but is not saved to configuration.

Normal/fast movement speeds remain **200 / 2000 m/s**, and position accelerations remain **80 / 800 m/s²**.
