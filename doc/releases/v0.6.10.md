## Cinematic/general mode

- **Main-keyboard `0` switches modes** while free camera is active. Cinematic mode is **on by default**, and the choice is saved locally across free-camera sessions and game restarts. Numpad `0` is not the default shortcut.
- **Cinematic mode:** movement keys (`W/A/S/D/Q/E` by default) and quick-menu direction buttons retain the existing camera speed and acceleration behavior.
- **General mode:** camera position movement stops immediately with no residual glide. Movement keys return to the native vehicle/avatar controls, including Q/E yaw with the default game bindings. Quick-menu movement and speed buttons are disabled.
- Mouse look, target focus, manual FOV and automatic FOV remain available in both modes. A mode switch does not clear the target, interrupt an ongoing drag or reset FOV smoothing.
- Both plugin menus display the current mode and provide a toggle. The shortcut respects menus, dialogs, text/chat entry, the console and application focus.
- Keyboard ownership restores each binding's original enabled state. Modified-key bindings and other control-map categories are untouched. The plugin's mode keys remain captured while free camera is active; controls reloads and Rewired lifecycle events are handled.

Normal/fast speed and acceleration settings are unchanged. Switching cinematic movement off/on retains the speed choice within the same free-camera session, but movement resumes from rest. No in-menu key-binding editor is added.

New configuration entries in `BepInEx/config/local.sp2.freecamera.cfg`:

```ini
[Movement]
CinematicModeEnabled = true

[Keys]
ToggleCinematicMode = Alpha0
```
