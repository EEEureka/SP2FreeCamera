## Fixes

- **Level horizon on entry:** entering free camera now immediately resets roll to zero, instead of inheriting a tilted view from the previous camera. Position, heading, pitch and FOV are retained.
- **Uninterrupted mouse look over target boxes:** left-mouse dragging can start over a HUD target box and continue across its boundary without losing the accepted press.
- **Wheel input over target boxes:** manual FOV zoom and automatic-FOV reference-area adjustment continue to work while hovering over a target box and immediately after leaving it.
- Pointer routing uses the current frontmost UI raycast rather than delayed native hover/interaction flags. Middle-click focus selection shares the same boundary. Plugin menus, foreground game controls, dialogs, text entry and the console remain protected.

No new settings or key bindings are required. Automatic FOV, zoom smoothing, movement speeds and position accelerations are unchanged.

## Installation and upgrade

Download **SP2FreeCamera-v0.6.9-win-x64.zip**, close SimplePlanes 2, and extract all contents into the directory containing `SimplePlanes 2.exe`. The archive includes **BepInEx 5.4.23.5 Windows x64**. Merge existing folders; existing configuration is preserved because the package contains no personal settings or other plugins.
