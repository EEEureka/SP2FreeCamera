## Cinematic position movement

- Configure normal and fast position acceleration independently in the full settings menu (`ScrollLock`), then click **Apply values**.
- Normal acceleration defaults to **80 m/s²**; fast acceleration defaults to **800 m/s²**. Default movement speeds remain **200 / 2000 m/s**.
- Starts, braking, turns, reversals and speed changes use the active mode's acceleration. Switching modes preserves the current velocity and applies the new mode's rate, including deceleration when switching from fast to normal.
- The existing movement smoothing time softens the final transition. Setting a mode's acceleration to `0` disables its limit; set that acceleration and movement smoothing to `0` for instant movement.
- Acquiring a focus target preserves an ongoing camera move. Dynamic target rotation remains immediate on each rendered frame, and FOV zoom smoothing remains independent.

## Installation

Download **SP2FreeCamera-v0.6.7-win-x64.zip**, close SimplePlanes 2, and extract all contents into the directory containing `SimplePlanes 2.exe`. The archive includes **BepInEx 5.4.23.5 Windows x64**. Merge existing folders; the package contains no personal configuration or other plugins.

Existing settings are preserved. New acceleration keys are added under `[Movement]` as `NormalAcceleration` and `FastAcceleration` with defaults `80` and `800`.
